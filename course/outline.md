# Codex 科研辅助课程大纲（参考资料初稿）

> **编制说明：** 本大纲依据 `reference/README.md` 和 `reference/Codex论文辅助全流程口播稿.md` 整理，供备课和讨论使用。以下七个主题沿用参考提要的顺序，不代表已确认的最终课程框架；后续安排以授课者指导为准。

## 第一章：综合能力较强的五个学术 Skill

### 1.1 Scientific Agent Skills

介绍覆盖科学计算、数据分析和可视化等能力的工具包，以及它在自然科学、生物医学和化学研究中的适用场景。

### 1.2 Nature Skills

概述口播稿所介绍的 Nature Skills，说明其覆盖研究构思、文献调研、论文写作和科研绘图等环节。

### 1.3 Academic Research Skill

介绍通过苏格拉底式提问帮助研究者澄清 Idea、打磨论文架构的用法。

### 1.4 Codex Auto Research

说明其面向计算机和人工智能研究的实验、参数调整、数据分析与脚本运行等任务。

### 1.5 Codex Cloud Academic Skills

介绍口播稿中面向中文论文及人工智能相关论文的使用场景。

## 第二章：文献管理

### 2.1 使用 Skill 检索文献及其局限

介绍通过 Skill 开展文献检索的基本方式，并说明检索覆盖不全、只能获取标题或摘要，以及下载流程受限等问题。

### 2.2 使用 AI 文献调研网站

说明如何设定调研范围、根据初步结果继续收紧问题，并获取文献调研报告。

### 2.3 使用文献关联与可视化工具

介绍借助论文关系图和文献库可视化发现相关论文、主题联系及作者关联。

### 2.4 将 Codex 与 Zotero 连接

梳理从调研结果中筛选文献、保存到 Zotero，再由 Codex 读取文献库并辅助总结、整理和引用的工作流程。

## 第三章：Idea 与论文架构

### 3.1 明确研究问题与研究缺口

说明如何澄清核心 Idea，辨认研究缺口，并提炼论文希望读者接受的主要观点。

### 3.2 通过苏格拉底式问答打磨 Idea

介绍让 AI 以追问和审视的方式检查研究设想，并通过多轮讨论完善论点。

### 3.3 先阅读相关论文，再开展构思

说明先整理并阅读最相关的一组论文，再基于具体研究方向与领域背景开展讨论。

### 3.4 从研究构思过渡到论文架构

介绍如何根据研究问题和相关文献梳理论文整体结构，并为后续写作明确待补充内容。

## 第四章：不同学科的论文写作

### 4.1 自然科学、医学、生命科学与材料科学

概述口播稿推荐的 Scientific Agent Skills、Nature Skills 等工具及其在相关论文写作中的使用方向。

### 4.2 计算机、人工智能与机器学习

说明这一类论文在研究范式上的特点，并介绍口播稿推荐的实验研究与学术写作类 Skill。

### 4.3 人文社科

介绍可用于人文社科论文构思和写作的通用学术研究类及社会科学写作类 Skill。

## 第五章：数据分析与科研绘图

### 5.1 数据分析与科研技能

概述借助科学研究类 Skill 开展数据分析和可视化的方式。

### 5.2 用生成式图像辅助构图

说明生成式图像可以用于探索整体构图和视觉表达；口播稿提醒，这类生成图应作为构思参考，不直接作为正式论文图表。

### 5.3 用数据和绘图工具制作论文图表

介绍使用 Python 等工具按实际数据绘图，并通过科研绘图或排版工具组合、完善图表。

## 第六章：科研 PPT 制作

### 6.1 将论文内容转化为汇报材料

说明如何围绕论文内容组织组会或课程汇报，并借助页面设计类 Skill 生成演示材料。

### 6.2 生成后检查与修改

结合口播稿中的课程 PPT 示例，概述如何对初稿继续修改，完善信息表达和视觉呈现。

## 第七章：论文日报与周报

### 7.1 设置周期性论文追踪

介绍通过定时任务持续检索指定研究方向的新论文，并按需要调整关注主题。

### 7.2 汇总每日或每周研究动态

概述追踪报告可包含的代表性论文、研究脉络和后续值得关注的方向。

### 7.3 回顾全流程并明确人工把关

回顾文献整理、Idea 打磨、分学科写作、数据分析与绘图、成果汇报和持续追踪等环节；强调研究者仍需亲自阅读文献、判断创新性并核对 AI 辅助内容。
